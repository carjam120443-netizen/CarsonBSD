# CarsonBSD Logo

This directory contains the official CarsonBSD operating-system logo and its source assets.

## Main logo

The main logo should be suitable for:

- the operating system boot experience
- the installer
- desktop branding
- `cbfetch`
- the project website and repository
- release artwork

Keep the primary logo recognizable at both large and small sizes. SVG is preferred for the canonical source artwork.

## Planned files

- `carsonbsd.svg` — canonical vector logo
- `carsonbsd-mark.svg` — standalone symbol/mark
- `carsonbsd-wordmark.svg` — wordmark variant
- `README.md` — logo usage notes
